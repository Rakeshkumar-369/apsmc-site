**Announcements / News**
GET /api/announcements (get all news)
POST /api/announcements (add a new one)
DELETE /api/announcements/:id (delete a specific one)

**Image Gallery**
GET /api/gallery (get all images)
POST /api/gallery (upload a new image)
DELETE /api/gallery/:id (delete an image)

**Organisation Members**
GET /api/organisation (get all members)
POST /api/organisation (add a new member)
DELETE /api/organisation/:id (delete a member)

**Documents (PDFs)**
GET /api/documents (get all documents)
POST /api/documents (upload a new one, needs title and category)
DELETE /api/documents/:id (delete a document)

**Site Settings**
GET /api/settings/chairman (get the chairman's info)
POST /api/settings/chairman (update chairman's info)
GET /api/settings/admin-structure (get the admin structure image URL)
POST /api/settings/admin-structure (update the admin structure image)
